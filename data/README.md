# Data

Download both CSV files from Kaggle (https://www.kaggle.com/datasets/ulrikthygepedersen/nba-player-salaries/data) and place them in this directory:

- players.csv - Player attributes and career performance statistics
- salaries_1985to2018.csv - Season-by-season salary data (1985-2018)

Then update the file paths in finalProject.Rmd to point to data/ instead of ../dataset/.
